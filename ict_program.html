    Information and Communication Technology Class program

  • Introduction
  • The ict program is designed to help students understand the basic concepts of information and communication technology Through this program,students will learn how technology is used in daily life,education, and workplace. Students will also develop practicial skills in website development and database management. This program prepares students to think creatively,solve problems, and build simple digital projects.

  • Learn MySQL
  • Technology Definitions:
  • HTML
  • HTML: HTML (HyperText Markup Language) is the standard markup language used to create and structure content on web pages
  • CSS
  • CSS: CSS (Cascading Style Sheets) is a style sheet language used to describe the presentation of a document written in HTML
  • JavaScript
  • JavaScript: JavaScript is a programming language that is commonly used to create interactive effects within web browsers
  • PHP
  • PHP: PHP (Hypertext Preprocessor) is a server-side scripting language that is used to create dynamic web pages and web applications
  • MySQL
  • MySQL: MySQL is an open-source relational database management system that is used to store and manage data for web applications
